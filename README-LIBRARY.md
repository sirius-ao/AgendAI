Sim. A distinção que implementei é:

| Menu | Finalidade |
|---|---|
| **Recursos** | Explorar materiais disponíveis e escolher o que usar numa aula. |
| **Biblioteca** | Guardar e organizar os seus materiais em pastas, com favoritos e lixeira. |

O percurso é: **encontrar em Recursos → guardar na Biblioteca → usar numa aula**. Também pode usar um recurso diretamente, sem o guardar primeiro.

**Atualmente, a diferença ainda é sobretudo de organização:** estamos no frontend, com dados locais. Recursos ainda não é um catálogo real partilhado entre professores, e os carregamentos guardam apenas os dados do ficheiro.

Se não pretendes ter um catálogo partilhado no futuro, eu juntaria os dois num único menu **Biblioteca**, com as abas **Explorar** e **Os meus materiais**. Isso simplificaria o dashboard.
