# Origem dos assets

Todas as fotografias provêm das imagens fornecidas pelo utilizador. Nenhuma fotografia foi gerada artificialmente. Os recortes foram convertidos para WebP com qualidade 90; os ficheiros originais não foram alterados.

| Asset                             | Referência | Região                                              |
| --------------------------------- | ---------- | --------------------------------------------------- |
| `home/hero-teacher.webp`          | `1.png`    | Professora e quadro, sem os benefícios da interface |
| `schools/school-team.webp`        | `4.png`    | Equipa de professores e edifício                    |
| `blog/teacher-writing.webp`       | `5.png`    | Fotografia superior da professora                   |
| `blog/lesson-plan.webp`           | `5.png`    | Fotografia do primeiro artigo                       |
| `blog/classroom.webp`             | `5.png`    | Fotografia do segundo artigo                        |
| `blog/attendance.webp`            | `5.png`    | Fotografia do tablet do terceiro artigo             |
| `blog/continuous-assessment.webp` | `5.png`    | Fotografia da avaliação                             |
| `blog/teacher-productivity.webp`  | `5.png`    | Fotografia da professora ao computador              |
| `blog/education-books.webp`       | `5.png`    | Fotografia dos livros                               |

Os textos manuscritos decorativos que já fazem parte das fotografias permanecem nos recortes. Navegação, títulos, botões, cartões, preços, formulários, ícones, previews de dashboards e documentos são componentes reais.

As referências `2.png` e `3.png` foram usadas para a reconstrução do mega menu e dos planos, sem extração de elementos da interface.
